# 路线 3｜研究成果

> 预登记 → 检验 → 独立复算 → 可复现报告
> 写于 2026-11-15。总览见 [`README.md`](./README.md)。

## 1. 目标与完成定义

产出 1–2 份**别人能复现、你本人能独立讲清楚**的研究成果。成果的价值在方法严谨，不在结论好看——「这个规则样本外不成立」是合格的结论。

每个课题全部满足才算完成：

- [ ] 研究卡先于结果提交 (commit 时间可查)
- [ ] 一条命令从数据重新生成全部表和图
- [ ] 报告里每个数字都能追到代码生成的结果表，没有手打的数字
- [ ] 关键数字被独立复算过 (另一个会话只拿规格和数据，不看代码)
- [ ] 局限和 AI 使用说明写明
- [ ] 你本人能不看稿回答 20 个追问

## 2. 两条线

### 线 A 量化实证 (依赖路线 1)

**课题 A1 (推荐先做)：一个技术面选股规则在 Bursa 的回测与前向模拟对照**

- 为什么选它：数据现成；模拟账户从 2026-09-30 起的记录是真正的前向样本；`strategy.json` 的 git 历史天然就是规则的时间戳。
- 现在的数字 (截至 2026-11-13，扣成本)：规则定下来之前 106 个信号平均 +4.05%；之后 26 个信号平均 −4.92% (3 笔还持有中)。详见 [`route1-quant-research.md`](./route1-quant-research.md) 第 2 节。
- 为什么还不能下结论：前向只有 26 笔；近期信号里亏的先出场，数字偏低；同期交易彼此相关；账本只统计今天还在报告里的股票。
- 研究卡里要预先写死的东西 (下面是示例，定稿时由你确认)：
  - 主指标：每个信号的扣成本净收益均值 (不是账户模式，账户模式受仓位数影响)
  - 前向期起点：`strategy.json` 最后一次改动的日期。**要用完整 git 历史核对**——如果 9/30 之后规则改过，前向期从最后一次改动重新起算
  - 样本量和日期：目标 300 个已结算信号 (按现在每月约 26 个，要到 2027 年下半年)；中期报告日 2027-03-31，到时不够就照实写「证据不足」
  - 检验：按信号日分块的 bootstrap 95% 置信区间
  - 结论三选一：区间下限 > 0 →「样本外支持」；上限 < 0 →「样本外不支持」；其余 →「证据不足」
  - 期间规则不许改；改了就是新课题，前向期清零
- 依赖：路线 1 的 P0 (去掉幸存者偏差要靠每日快照) 和 P1 (未来函数测试、进场口径核查)。

**课题 A2：公告事件研究** — 季报公布、UMA 质询、回购、大股东持股变动之后的异常收益。方法是标准的事件研究 (市场模型、累计异常收益、截面检验)，学术味更足。难点：公告历史要回补；公告只有日期没有时刻，盘后公告的事件日要顺延一天；来源有延迟 (`data/ann_latency.json` 已经在量)。

**课题 A3 (备选)：横截面因子在小盘股里扣掉跳一格成本后还剩多少** — 动量、低波、流动性。长历史只能用回补数据，带幸存者偏差，结论要打折。

### 线 B 估值 / 公司研究 (不依赖路线 1，随时能开始)

一份可复算的估值案例：

1. 输入表：每个数字带来源、日期、币种、单位、财年
2. 三表勾稽检查：资产 = 负债 + 权益；现金流量表的期末现金 = 资产负债表的现金；净利润到经营现金流的调节
3. 模型任选：DCF、分部加总 (SOTP)、EVA (= 税后营业利润 − 资本成本率 × 投入资本)
4. 敏感性矩阵 (折现率 × 长期增长)，写明终值占估值的比例
5. 情景表：每个情景的假设和触发条件；历史数字、预测数字、自己的情景分开标
6. 自校验：第二个会话只拿原始财报，重算关键比率，逐项对比

### 线 C (可选) 旧论文复现

手上有以前的实证论文和数据的话，拿来做一次「独立复算」练习：成本低，练的是同一套流程。

## 3. 研究流程 (每个课题都走)

| 步 | 做什么 | 过了才能往下 |
|---|---|---|
| 0 研究卡 | 一页：问题、假设、数据、样本、基准、主指标、判定规则 | 已提交，时间早于任何结果 |
| 1 数据审计 | 每个字段的可用日期；幸存者偏差；公司行动；异常值 | 审计表写完，已知问题列明 |
| 2 基线复现 | 先复现一个已知结果 (例如生产账本逐笔对上) | 对得上，或差异有解释 |
| 3 主检验 | 按研究卡的规格跑，规格不动 | 结果表由代码生成 |
| 4 稳健性 | 换窗口、换成本、分组 (板块 / 价格档 / 流动性档)、安慰剂 (随机日期、随机进场)；记下试过的全部变体 | 试验登记簿完整 |
| 5 自校验 | 见第 4 节 | 清单全过 |
| 6 写作 | 报告 + 局限 + AI 使用说明；数字全部来自结果表 | — |
| 7 打包 | 说明文件、环境锁定、一条命令复现、结果、PDF；确认哪些能公开 | 换一台机器能跑通 |

## 4. 自校验清单

- [ ] **独立复算**：另开一个会话，只给规格和数据，不给代码，重算主指标；两边在容差内一致
- [ ] **合成数据**：埋一个已知大小的效应，流程能找回来；不埋效应，误报率接近名义水平
- [ ] **未来函数**：截断一致性测试通过 (路线 1 P1)；信号用到的每个字段，可用日期都不晚于信号日
- [ ] **选择偏差**：样本怎么来的写清楚；剔除了什么、为什么
- [ ] **多重检验**：报告写明一共试了多少个变体，不只报最好的那个
- [ ] **对抗式复核**：让一个会话专门找这份研究的漏洞，逐条回应
- [ ] **数字溯源**：随机抽 10 个正文里的数字，都能在结果表里找到
- [ ] **可执行性**：进场价、成交量上限、跳一格成本在现实里做得到

## 5. 统计口径提醒

- 样本小就照实说小。25 笔、11 笔这种数量，只报区间，不谈显著
- 同一段时间的交易彼此相关，不能当成独立样本 → 按日期分块抽样
- 持有期重叠的收益不能直接做 t 检验
- 最近的信号有删失：亏的先出场。比较不同时期要么只比已走完的，要么用固定天数的收益 (账本里有 5 / 10 / 20 天)
- 回补的历史只含今天还上市的股票，用它得出的数字一律标「含幸存者偏差」
- 回测、模拟账户、实盘三者分开报，不混在一张表里

Python (pandas、statsmodels、scipy)；报告用 Markdown 或 Quarto 生成 PDF；参考文献用文献管理软件导出 APA 格式。量化课题的代码放路线 1 的研究仓库下面 `studies/<课题>/`；估值案例可以单独一个文件夹。

## 7. 护栏

- 研究卡提交之后不改判定规则；要改就另开课题
- 模型不手算数字；模型写的文字里出现的每个数字都要回表核对
- 报告不写买卖建议，不写目标价；个人交易经历只当动机背景，不当证据
- AI 参与了哪些部分照实写；每个方法你都要能用自己的话讲出来，讲不出来的不放进报告
- 原始行情和公告数据不随报告公开；公开的是代码、汇总结果、图
- 其余见 [`README.md`](./README.md) 第 7 节
